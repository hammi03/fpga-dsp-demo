## Filter Specification

| Parameter         | Value                                |
|-------------------|--------------------------------------|
| Architecture      | Direct-form FIR, fully registered    |
| Taps              | 8                                    |
| Data width        | 16-bit signed                        |
| Coefficient scale | x256 (2^8), sum = 256 -> DC gain = 1 |
| Cutoff frequency  | 0.25 * fs (Hamming window)           |
| Latency           | 1 clock cycle                        |
| Interface         | `valid_in` / `valid_out` handshake   |

### Coefficients

```
h = [-1, -6, 25, 110, 110, 25, -6, -1]   (scaled x256, symmetric)
```

Generated by `scripts/design_filter.py` — single source of truth.
Sum = 256 -> unity DC gain.  Symmetric -> H(Nyquist) = 0 exactly.

## Architecture

```
          data_in (16-bit signed)
               |
    +----------v--------------------------------------------------+
    |  tap_reg: shift register (8 x 16 bit)                       | clk
    |  tap_vec[0] = data_in  (variable -> same-cycle MAC)         |-->
    |  tap_vec[1] = tap_reg[0], ..., tap_vec[7] = tap_reg[6]     |
    +----------+--------------------------------------------------+
               |  8 taps (16-bit each)
    +----------v--------------------------------------------------+
    |  MAC:  acc = SUM( COEFFS[i] * tap_vec[i] )   (40-bit)      |
    +----------+--------------------------------------------------+
               |  acc[23:8]  (arithmetic right-shift by 8)
          data_out (16-bit signed)
```

**Key decisions:**

- **Variable for tap vector** — `data_in` feeds into the MAC in the same clock
  cycle via a VHDL variable; no extra latency vs. a two-process design.
- **40-bit accumulator** — worst-case product sum fits in 35 bits; 40 bits
  provides margin without wasting resources.
- **Arithmetic right-shift** — `acc[SCALE_SHIFT+15 : SCALE_SHIFT]` divides by
  256, consistent with two's-complement truncation towards -inf.
- **Standard VHDL-2008** — no vendor libraries; synthesises with GHDL,
  Xilinx Vivado, and Intel Quartus unchanged.

## Quick Start

### Prerequisites

- **GHDL** (simulation): `sudo apt install ghdl` (Linux / WSL)
- **Python 3** with `numpy scipy matplotlib`: `pip install numpy scipy matplotlib`

### Run simulation

```bash
make sim          # compile + simulate, writes results/sim.vcd
make clean        # remove build artefacts
```

Or via WSL from PowerShell:

```powershell
wsl -d Ubuntu -- bash -c "cd /mnt/c/path/to/fpga-dsp-demo && make sim"
```

### Generate plots

```bash
python scripts/design_filter.py   # frequency response
python scripts/plot_results.py    # VHDL vs Python comparison (needs sim.vcd)
```

### Expected simulation output

```
PASS  Impulse[0]  got=-1
PASS  Impulse[1]  got=-6
PASS  Impulse[2]  got=25
PASS  Impulse[3]  got=110
PASS  Impulse[4]  got=110
PASS  Impulse[5]  got=25
PASS  Impulse[6]  got=-6
PASS  Impulse[7]  got=-1
PASS  DC steady-state = 1000
PASS  Nyquist rejection (alternating +-1000 -> 0)
=== Simulation complete ===
```
